REA + Google Antigravity

Is guide mein seekhenge ki REA ko Antigravity coding agent se connect kaise karein, website ka visible structure inspect kaise karein, aur evidence ke basis par similar project build aur test kaise karein.

Example target website: https://ragsystemnotes.vercel.app/

1. Concepts — easy explanation

Antigravity

AI coding environment jahan hum natural language mein task dete hain. Agent project files inspect karne, code likhne aur testing mein help kar sakta hai.

REA

Reverse Engineer Anything ek MCP server aur CLI toolkit hai jo supported targets ko inspect karne ke tools agent ko deta hai. Ye original source code recover karne ki guarantee nahi deta.

MCP

Model Context Protocol ek standard bridge hai jisse AI agent external tools se context le sakta hai aur unki defined capabilities use kar sakta hai.

Yaad rakho: MCP connected hone ka matlab tools available hain; har tool har target par guaranteed kaam karega, aisa nahi.

2. Requirements & REA setup

  • Windows computer and internet
  • Node.js and npm installed
  • Google Antigravity installed
  • Project folder, example D:\check_rea

Check Node and npm

PowerShell / Terminal 
node -v
npm -v

Run REA setup

PowerShell / Terminal 
npx rea-agents setup

Setup wizard mein Antigravity select karo. Proposed changes aur file paths review karke hi approve karo. Skill install karna aur MCP server register karna alag cheezein ho sakti hain.

Diagnostic command

PowerShell / Terminal 
npx -y rea-agents@latest doctor --json

Output environment aur version ke hisaab se vary kar sakta hai.

3. Verify MCP connection

1
Antigravity mein Settings → Customizations → Installed MCP Servers kholo.
2
REA / Reverse Engineer Anything listed aur enabled hai ya nahi check karo.
3
New conversation mein ye test prompt do:
Prompt — connection test 
Check whether the REA (Reverse Engineer Anything) MCP server is connected. List the available REA MCP tools and perform a simple connection test. Do not inspect or modify any website yet. If the server is unavailable, explain what configuration is missing.

Config paths (reference)

Global config 
C:\Users\YOUR_USERNAME\.gemini\config\mcp_config.json
Workspace config 
.agents\mcp_config.json

Agar setup already connection configure kar chuka hai, bina wajah JSON manually edit mat karo.

4. Website reconnaissance

Reconnaissance ka matlab implementation se pehle visible website ko systematically samajhna: pages, anchors, layout, colors, typography, components, interactions, assets aur reliably identifiable technologies.

Prompt — read-only inspection 
Use the connected REA MCP tools to inspect this website:
https://ragsystemnotes.vercel.app/

Perform read-only reconnaissance only. Do not modify files or deploy anything.

Inspect:
1. Pages and in-page anchor links
2. Overall layout and visual design
3. Colors, typography, spacing, and reusable components
4. Buttons and visible interactions
5. Images, icons, and assets
6. Technologies that can be reliably identified

Start with the homepage and keep the inspection bounded. Return a structured report with findings, uncertainties, and next steps. Do not implement the website yet.

Our example findings

AreaObserved result
StructureOne main document with anchors: #setup, #phase1, #phase2, #phase3, #run.
LayoutSticky top navigation, centered reading column, max width around 860px, footer separator.
ThemeBlack background, dark panels, subtle borders, light text, blue accent, amber warning callouts.
ComponentsInfo/warning notes and code panels with file labels and Copy buttons.
InteractionsSmooth anchor scrolling and clipboard-copy feedback.
AssetsNo regular image assets/icon library found in the inspection; favicon request returned 404.
TechReport identified vanilla HTML/CSS and a small amount of JavaScript; Vercel response headers were observed.
Evidence vs assumption: One page visit cannot prove hidden routes do not exist. Describe what was observed and clearly label uncertainty.

5. Prompt to build the replica

Analysis complete ho jaaye, tab implementation prompt use karo. Isse agent ko current workspace dobara open karne ko nahi kehna padega.

Prompt — implement and test 
The reconnaissance of https://ragsystemnotes.vercel.app/ is already complete. Build a faithful local replica in my CURRENT workspace. Do not repeat the full reconnaissance unless details are missing.

1. Inspect existing files first and preserve unrelated work.
2. Use Vanilla HTML5, CSS3, and JavaScript. Avoid frameworks and unnecessary dependencies.
3. Match the black background, dark panels, borders, light text, blue accent, centered reading column, sticky blurred navigation, typography, spacing, notes, code panels, and footer.
4. Implement working anchor navigation, smooth scrolling, responsive layout, and Copy buttons that copy the correct code and briefly show “Copied”.
5. Preserve actual tutorial text and code examples. Do not invent missing content or use placeholders. Report any gaps.
6. Add a simple favicon.
7. Run locally, open in a browser, test navigation and copy buttons, check mobile layout and console errors, and fix issues found.
8. Do not deploy or modify the original website.
9. Report files changed, how to run it, tests performed, and unresolved issues.

Start implementing and testing in the current workspace. Do not ask me to open the workspace again.
Prompt formula: Context + Goal + Constraints + Verification + Final report. “Make a website” alone is usually too vague.

7. Troubleshooting

“No MCP servers configured”

Skill aur MCP registration alag ho sakte hain. Setup wizard run karke Antigravity select karo, proposed changes review karo, approve karo, phir app restart/reload karke verify karo.

Agent “Working…” par atka hai

  • Task ko chhote steps mein divide karo.
  • Homepage-only bounded inspection se start karo.
  • Check karo tool call running hai ya error aaya.
  • Stuck ho to cancel karke last completed step aur error maango.

Content missing hai

Missing headings/snippets specifically identify karwao. Source content unavailable ho to invented code add karne ke bajay gap document karo.

Copy button fails

Console, clipboard permissions, localhost/HTTPS aur button-to-code-block mapping check karo.

8. Responsible use and limitations

  • Sirf authorized ya publicly accessible sites ko applicable terms follow karte hue inspect karo.
  • Passwords, API keys, private data ya secrets prompts/reports mein mat paste karo.
  • Design patterns se seekho; logos, branding aur proprietary assets permission ke bina copy/distribute mat karo.
  • REA evidence provide karta hai; guaranteed original source-code recovery tool nahi hai.
  • Apne implementation ko tests aur documented assumptions ke saath maintain karo.

10. One-minute recap

  1. Antigravity is the AI coding environment.
  2. MCP connects an agent to external tools.
  3. REA provides inspection/reverse-engineering tools.
  4. Reconnaissance gathers evidence before implementation.
  5. Prompting defines scope, constraints and success criteria.
  6. Implementation should preserve content and avoid guessing.
  7. Testing verifies the result actually works.
Teaching formula: Connect → Verify → Inspect → Plan → Build → Test → Report.
